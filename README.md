# UPTennis 全国门店照片册

Interactive store photo gallery website.

## Setup

1. Go to **Settings > Pages** in this repo
2. Select **Deploy from a branch** → **main** → **/(root)**
3. Save
4. Your site will be live at: **https://HenryC0426.github.io/uptennis-gallery/**

## Photos

Upload the `photos/` folder to this repo to display all store images.

## Structure

- `index.html` — Main website
- `photos/` — Store photos organized by city
